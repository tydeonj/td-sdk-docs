后台配置

建应用、广告位、广告源和瀑布流。正式包只用您自己的 App ID / 广告位 ID。

集成 SDK

Android 走 Maven（Manifest、混淆）；iOS 走 CocoaPods（ATS、ATT、SKAdNetwork）。

五种广告

激励、插屏、开屏、横幅、原生。统一 Load → isReady → Show，不会自动展示。

隐私默认开

不必调用 setPrivacyUserAgree(true)。JinDai / AdGain 需要 OAID 或 IDFA。

正式上线请使用后台为您的应用签发的 App ID、广告位 ID。正文示例一律写 YOUR_APP_ID / YOUR_AD_UNIT_ID。

SDK 不会在 Load 成功后自动 Show。原生自渲染要先拼布局再 Show。完整字段与合规披露见 隐私合规。

推荐顺序 ​

  1. 后台配置：应用 → 广告位 → 广告源 → 瀑布流
  2. 只看您的端：Android 集成 或 iOS 集成
  3. 初始化（用户同意隐私政策之后；仅主进程 / didFinishLaunching）
  4. 按格式抄 Load → isReady → Show
  5. 测试验收
